# 2048

纯原生 HTML / CSS / JavaScript 实现的 2048 小游戏，单文件、零依赖、可离线运行。

## 在线试玩

https://andows7.github.io/2048/

## 功能

- 方向键 / WASD 移动，手机端支持滑动
- 合并动画、得分浮动提示、深色主题
- 最高分本地保存（localStorage）
- 撤销（Ctrl+Z，最多 20 步）
- 达成 2048 后可继续挑战，无路可走自动结算

## 本地运行

直接用浏览器打开 `index.html` 即可，无需构建。

## 部署

推送到 `main` 分支后，GitHub Actions 会自动发布到 GitHub Pages。
